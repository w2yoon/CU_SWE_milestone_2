### Invitations

Invitation object: `{code, workspace_id, max_uses, uses, expires_at, invited_user_id, invited_username, created_by}`; `code` is a non-empty URL-safe string.

| ID | Request | Required result |
|---|---|---|
| A6.1 / A6.1b | `POST /api/workspaces/{slug}/invitations` by `member` / no token | `403` / `401` |
| A6.2 | same by admin or owner, body `{expires_in_seconds?, max_uses?, invited_username?, invited_user_id?}` | `201 {invitation}` with `code`; `max_uses` defaults to `1`; targeted invitations are single-use |
| A6.3 / A6.3b | `GET /api/workspaces/{slug}/invitations` by admin/owner / by member | `200 {invitations:[...active only...]}` / `403` |
| A6.4 / A6.4b | `POST /api/invitations/{code}/accept` by a non-member | `200`; caller becomes workspace `member`; consumes exactly one use |
| A6.5 | accept again after `max_uses` reached | `404` |
| A6.6 | unknown code | `404` |
| A6.7 | someone other than `invited_user_id` accepts a targeted invite | `403` |
| A6.8–A6.10 | `max_uses:2` | first two accepts `200`, third `404` |
| A6.11 | `expires_in_seconds:1`, accept after 2 s | `404` |
| A6.12 | `DELETE /api/workspaces/{slug}/invitations/{code}` by `member` | `403` |
| A6.13 | same by admin/owner | `200 {"deleted":true}` |
| A6.14 | accept a revoked code | `404` |

Active = not revoked, not expired, `uses < max_uses`. `invited_username` resolves to a user id when the invitation is created.
