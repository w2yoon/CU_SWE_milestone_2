### Roles (`owner`, `admin`, `member`, `guest`)

`PATCH /api/workspaces/{slug}/members/{user_id}` body `{role}` → `200 {member:{user_id, role, username, display_name}}`.
Evaluate in this order: caller must be `owner`/`admin` (else `403`) → target must be a member (else `404`) → target is `owner` (`403`) → caller is `admin` and target is `admin` (`403`) → `role` is `owner` (`400`) or not one of `admin|member|guest` (`400`) → apply.

| ID | Request | Required result |
|---|---|---|
| A4.1 / A4.3 | owner sets a member → `admin`, then admin → `member` | `200`, `member.role` updated |
| A4.2 | admin tries to change another admin | `403` |
| A4.4 / A4.5 | admin sets member → `guest`, guest → `member` | `200` |
| A4.6 | owner PATCHes a member with `{role:"owner"}` | `400` (use transfer_ownership) |
| A4.7 | admin PATCHes the owner | `403` |
| A4.8 | owner PATCHes their own role | `403` (owner role immutable via PATCH) |
| A4.9 | a plain `member` PATCHes anyone | `403` |
| A4.10 | PATCH with no token | `401` |
| A4.11 | `{role:"superuser"}` | `400` |

| ID | Request | Required result |

### Role-based channel permissions

| ID | Request | Required result |
|---|---|---|
| A5.0 / A5.4 | `POST /api/workspaces/{slug}/channels {name}` (public) by owner / admin / member | `201` |
| A5.1 | `POST /api/channels/{id}/join` by a `guest` on a public channel | `403` |
| A5.2 | guest creates any channel | `403` |
| A5.3 | `member` creates `{is_private:true}` | `403` |
| A5.5 | `admin` or `owner` creates private channel | `201` |
| A5.6 | join a private channel without being a channel member | `403` (private channels are never joinable through `/join`; already-a-member → `200`) |
| A5.7 | non-workspace-member creates a channel | `403` |

`POST /api/channels/{id}/join` decision order: 401 → 404 unknown channel → caller is workspace `guest` ⇒ 403 → channel private ⇒ 403 (unless already a channel member ⇒ 200) → caller not a workspace member: `open` ⇒ add as workspace `member`, `invite_only` ⇒ 403 → add to channel ⇒ `200 {channel}` (idempotent).
