### Read state

`GET /api/channels/{id}/read` → `200 {read_state:{channel_id, last_read_event_id, unread_count, mention_count}}`; `POST` same route `{last_read_event_id}` → `200 {read_state}`.

- `unread_count` = non-deleted messages (top-level and replies) in the channel authored by someone else whose `event_id > last_read_event_id`. Store the channel `event_id` on each message row.
- `mention_count` = those unread messages whose `mentions` contain the caller (a user's own messages never count).
- `POST` never lowers `last_read_event_id` (a smaller value is ignored; the stored larger value is returned).

| ID | Request | Required result |
|---|---|---|
| B3.8–B3.10 | GET read for a member / owner | shape above; member `unread_count ≥ 6`, `mention_count ≥ 3`; owner `mention_count == 1` (self-mentions excluded) |
| B3.11 / B3.12 | POST `4` then POST `2` | `last_read_event_id` is `4` both times |
| B3.13 | GET after reading up to 4 | `unread_count` decreased |
| B3.14 | `GET /api/workspaces/{slug}` | includes `read_state` (same per-channel shape) |
| B3.15 | no token | `401` |
