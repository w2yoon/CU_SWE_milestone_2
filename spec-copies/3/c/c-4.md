### User groups

`GroupObj = {id, handle, name, member_user_ids}` — responses use `member_user_ids` (never `members`); request bodies use `user_ids`. `handle` matches `^[a-z0-9][a-z0-9_-]{0,31}$`, unique per workspace. Store the creator id.

| ID | Request | Required result |
|---|---|---|
| C4.1 | `POST /api/workspaces/{slug}/groups {handle,name,user_ids}` by any workspace member | `201 {group}` |
| C4.2 | same handle again / bad handle (`Bad Handle`) / missing name | `409` / `400` / `400` |
| C4.3 | non-member of the workspace / no token / unknown slug | `403` / `401` / `404` |
| C4.4 | `GET /api/workspaces/{slug}/groups` | `200 {groups:[GroupObj]}` |
| C4.5 | `PATCH /api/workspaces/{slug}/groups/{handle} {name?, user_ids?}` by the creator | `200 {group}` updated |
| C4.6 | PATCH by another plain member / by the workspace owner / unknown handle | `403` / `200` / `404` |
| C4.7 | `DELETE .../groups/{handle}` by another plain member / by the creator / again | `403` / `200 {"deleted":true}` / `200 {"deleted":true}` (idempotent) |

### Group and @here mentions (extend `mentions` of B.3 / basics)

- `@<handle>` of a group in the channel's workspace expands to group members who are also members of the destination channel, excluding the author.
- `@here` expands to channel members, except the author, that currently have an open WebSocket on ANY node. Track this in a shared table `presence(conn_id, user_id, node_id)`: insert on WebSocket accept, delete when the socket closes; on node start delete rows with this `node_id`.
- `mentions` = union of all forms (`@username`, `@channel`, `@handle`, `@here`), deduplicated, never the author.

| ID | Body | `mentions` |
|---|---|---|
| C4.8 | `@devs ship it` (devs = {author, A, B, C}; A and B in the channel, C not) | `[A, B]` (any order) |
| C4.9 | `@devs and @A` | `[A, B]` (deduped) |
| C4.10 | `@here` while A has a WebSocket open on node 8001 and B has none (author also connected) | `[A]` |
| C4.11 | `@here` after A closed the socket (≤ 1 s ago) | `[]` |
