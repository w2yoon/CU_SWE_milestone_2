## Conventions (apply to every endpoint below)

- Base `http://127.0.0.1:8000` (nodes `:8000 :8001 :8002` all serve the same data). Routes under `/api/...`, JSON in/out.
- Auth header `Authorization: Bearer <token>`. Missing/invalid token on an authenticated route → `401`.
- Success: `200` read/update, `201` create. Errors: `400` validation, `401` auth, `403` forbidden, `404` unknown id, `409` conflict, `413` upload too large, `423` archived channel write.
- Responses use one top-level resource key (`user`, `message`, `file`, `group`, `groups`, `reactions`, `channel`, ...).
- Check order for every route: **401 (auth) → 404 (unknown id) → 403 (permission) → 400 (body validation)**.
- Timestamps: UTC ISO-8601 with `Z`, e.g. `2026-05-16T08:07:34.123Z`.
- ALL state lives in the shared SQLite file (or files under `/app/data`), never in process memory: any node may be killed at any moment.


Soft-delete: keep the row with `deleted_at`; deleted messages never appear in history, replies, search or pins, never count in `reply_count`/unread, and their reactions no longer count.

| ID | Request | Required result |
|---|---|---|
| E1.1 | `PATCH /api/messages/{id} {"body":"new"}` by the author | `200 {message}` with the new `body` and `edited_at` set (UTC `Z` string; `null` before any edit) |
| E1.2 | history after E1.1 | shows the new body and `edited_at` |
| E1.3 | PATCH by someone else (even the workspace owner) | `403` |
| E1.4 | PATCH with empty/blank body / unknown id / no token | `400` / `404` / `401` |
| E1.5 | `DELETE /api/messages/{id}` by the author | `200 {"deleted":true}` |
| E1.6 | DELETE again | `200 {"deleted":true}` (idempotent) |
| E1.7 | history after delete | the message is gone; a parent's `reply_count` drops when a reply is deleted |
| E1.8 | PATCH a deleted message | `409` |
| E1.9 | DELETE by the workspace owner of someone else's message / by another plain member | `200` / `403` |
| E1.10 | WebSocket subscriber | gets `message.updated` (with `message`) and `message.deleted` (with `message_id`), dense ids |
| E1.11 | edit or delete in an archived channel | `423` |
