# Component C — features built on messages — stage C.3 of C.1–C.5 (slash commands)

Build ONLY this stage now. Earlier stages must already pass. Check: `bash /spec/c/checks/check_c_3.sh`.

**Functions used from earlier stages:** `create_message`, `patch_topic`, `set_archived`, `join_channel` / channel membership insert, `emit_event`

**Functions added in this stage:** `run_slash(conn,user,channel,body)` called first in `POST /api/channels/{id}/messages`

A `body` starting with `/` (after nothing else, no leading spaces) is a command. Parse `/<name> <rest>`.

| ID | Body posted | Required result |
|---|---|---|
| C3.1 | `/me waves` | `201 {message}` normal message, `body` exactly `"/me waves"` |
| C3.2 | `/me` or `/me   ` | `400` |
| C3.3 | `/shrug hi` | `201`, `body` = `hi ¯\_(ツ)_/¯` (text, one space, the emoticon `¯\_(ツ)_/¯` with ONE backslash) |
| C3.4 | `/shrug` | `201`, `body` = `¯\_(ツ)_/¯` |
| C3.5 | `/topic New topic` | `201 {message:null, channel:{...,topic:"New topic"}}`; emits `channel.updated`; topic > 250 chars → `400` |
| C3.6 | `/invite @bob` (bob is a workspace member not in the channel) | `201 {message:null, invited_user:UserObj}`; bob is now a channel member (`member.joined` event); unknown user → `404` |
| C3.7 | `/archive` by the workspace owner | `201 {message:null, channel:{...,is_archived:true}}`; a normal post now → `423` |
| C3.8 | `/unarchive` by the owner on that archived channel | `201 {message:null, channel:{...,is_archived:false}}` (this command is allowed while archived) |
| C3.9 | `/archive` or `/unarchive` by a non-owner | `403` |
| C3.10 | `/bogus thing` | `400` (unknown command) |
| C3.11 | `//literal text` | `201`, a normal message whose `body` is exactly `"//literal text"` (not a command) |

Side-effect commands (`/topic`, `/invite`, `/archive`, `/unarchive`) create no message row and return the key `message` with JSON `null`.
