### Reactions

Table `reactions(message_id, user_id, emoji, PRIMARY KEY(message_id,user_id,emoji))`. `reactions` = `[{emoji, count, user_ids}]`, one entry per emoji with `count ≥ 1` (count = len(user_ids)); emojis whose count is 0 are not listed. Every `MessageObj` (POST response, history, replies) carries this list.

| ID | Request | Required result |
|---|---|---|
| C1.1 | `POST /api/messages/{id}/reactions {"emoji":"👍"}` by a channel member | `200 {reactions:[{emoji:"👍",count:1,user_ids:[me]}]}` (200, not 201, even on first insert) |
| C1.2 | same request again | `200`, still `count:1` (idempotent per user+emoji) |
| C1.3 | a second user adds `👍`, then `🎉` | `👍` has `count:2` and both ids; `🎉` is a separate entry |
| C1.4 | `GET /api/channels/{id}/messages` | the message's `reactions` equals the last response |
| C1.5 | `DELETE /api/messages/{id}/reactions/{emoji}` (emoji URL-encoded) | `200 {reactions}` without the caller's id; an emoji whose count drops to 0 disappears |
| C1.6 | no token / unknown message id / `{"emoji":""}` or missing emoji | `401` / `404` / `400` |
| C1.7 | non-member of a private channel reacts | `403` |
| C1.8 | WebSocket subscriber of the channel | receives `reaction.added` then `reaction.removed`, each with `event_id`, `channel_id`, `message_id`, `emoji`, `user_id`, ids dense |
| C1.9 | reacting in an archived channel | `423` |

A repeated add or a remove of a reaction that does not exist changes nothing and emits no event.

### DMs

| ID | Request | Required result |
|---|---|---|
| C1.10 | `POST /api/dms {"user_id":B}` by A | `200 {channel_id}` |
| C1.11 | B calls with A's id; A calls again | the same `channel_id` every time (store the pair sorted; create in one transaction) |
| C1.12 | unknown `user_id` / missing `user_id` / no token | `404` / `400` / `401` |
| C1.13 | A and B post and read history in the DM channel | `201` / `200` |
| C1.14 | a third user reads or posts in the DM channel | `403` |

The DM channel is a channel row with `is_dm:true`, `is_private:true`, members exactly A and B, and it is not listed among a workspace's channels.
