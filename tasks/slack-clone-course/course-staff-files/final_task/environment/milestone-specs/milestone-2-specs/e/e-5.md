# Component E — IRC, web UI and message edits — stage E.5 of E.1–E.5 (SPA messages, threads, reactions)

Build ONLY this stage now. Earlier stages must already pass. Check: `bash /spec/e/checks/check_e_5.sh`.

**Functions used from earlier stages:** E.4 SPA (`api`, `selectChannel`), E.1 edit/delete API, B.2 replies API, C.1 reactions API (`POST /api/messages/{id}/reactions`, `DELETE /api/messages/{id}/reactions/{emoji}`, `reactions:[{emoji,count,user_ids}]` on MessageObj — if C is not in `/spec`, build just these two routes as described in this line)

**Functions added in this stage:** JS `renderMessage(m)`, `startEdit(m)`, `openThread(m)`, `openEmojiPicker(m)`; live refresh via `/api/ws` subscribe (or polling every ≤ 2 s)

Each message row is `[data-testid=message]` with `data-message-id`, containing `[data-testid=message-avatar]` (initials circle), `[data-testid=message-author]` (display name), `[data-testid=message-time]` (human-readable, e.g. `3:04 PM`, never a raw ISO string), `[data-testid=message-body]`, and a hover toolbar (shown on `:hover`, CSS only) with buttons `[data-testid=edit-message-btn]` (author only), `[data-testid=delete-message-btn]`, `[data-testid=open-thread-btn]`, `[data-testid=reaction-button]`. Top-level messages only in `message-list` (oldest at the top, newest at the bottom); replies only in `thread-panel`.

| ID | Behaviour | Required result |
|---|---|---|
| E5.1 | open a channel with no messages | `[data-testid=empty-channel]` visible with non-blank text (e.g. `No messages yet — say hi!`) |
| E5.2 | type in `message-input`, click `send-btn` (Enter also sends) | a `message` row with that `message-body`, plus non-empty avatar, author and time; the input is cleared |
| E5.3 | click `send-btn` with an empty or blank input | no new row, no request; input keeps focus |
| E5.4 | hard reload | the message is still there (token from localStorage, channel reselected or `general`) |
| E5.5 | hover → `edit-message-btn` → `[data-testid=edit-input]` prefilled → type new text → Enter | `message-body` shows the new text and `[data-testid=edited-indicator]` (text `(edited)`) is visible; still so after reload |
| E5.6 | hover → `delete-message-btn` | the row disappears at once (no confirm dialog) and stays gone after reload |
| E5.7 | hover → `reaction-button` | `emoji-picker` visible as a grid (`display:grid`) with ≥ 6 `emoji-option` buttons; clicking one closes it and shows a `reaction-chip` with that emoji and count `1`; clicking the chip again removes your reaction |
| E5.8 | hover → `open-thread-btn` | `thread-panel` visible to the right of `message-list`, showing the parent; `thread-input` + `thread-send` posts a reply (with `parent_id`) shown in the panel; the parent row shows `[data-testid=reply-count]` with text `1 reply` (then `N replies`); `close-thread` hides the panel |
| E5.9 | a message posted by another user through the API | appears in the open channel within 3 s without reload |
